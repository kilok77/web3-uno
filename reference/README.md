# Reference Material

Keep original, authoritative course material here without unnecessary duplication:

- [`assignments/`](assignments/) — assignment specifications and related handouts;
- [`rules/`](rules/) — supplied UNO rules or rule references;
- [`tests/`](tests/) — supplied test suites or test archives that are not yet placed inside an assignment snapshot.

Preserve original filenames where practical. Do not edit supplied tests to accommodate an implementation. When material must remain elsewhere to keep an existing project working, document its existing location here instead of moving it.

Current material includes all six assignment DOCX files, the supplied UNO rules PDF, the OO test ZIP, and the functional-test ZIP. The OO archive has also been extracted to `tests/oo-model/` for read-only analysis while retaining the original ZIP.
